## THE PRINCIPLE

A seat that owns 2 seconds of a 15-second video should not score the same as a seat that owns
whether anyone watches at all. **Weights come from the retention data, not from fairness.**

```
71% of viewers decide in the opening seconds   -> the hook carries the most weight
shares/DMs drive distribution                  -> the twist and share-trigger carry the next most
craft matters, but only AFTER attention exists -> execution seats weigh less
```

## PART 1 — THE HARD GATES (pass/fail, before any scoring)

**These are mechanical. They cannot be argued around, and a fail zeroes the video.**

```
[] Frame 1 contains motion / something happening (not posed, not empty)
[] Hook has BOTH layers - visual AND verbal/text
[] Twist exists and is a REFRAME (not merely a surprise)
[] Exactly ONE CTA
[] Loop closes (last beat rhymes with first)
[] 9:16 · first frame not black · captions in safe zone
[] Audio: STEREO · -7 to -9 LUFS · body 150-1500Hz >= 35%
[] Bank 10 accuracy: correct grille/generation/engine-note/RHD/plate
[] AI disclosed on post
ANY FAIL -> the video does not ship. No score is calculated.
```

## THE BANDS
```
90-100  SHIP + push hard. Boost it. This is a format worth repeating
80-89   SHIP. Solid. Log what worked
70-79   SHIP but note the weak seat. Fix it next episode
60-69   REVISE one seat, re-score. Do not ship yet
<60     REDESIGN. The concept is wrong, not the execution -> back to Strategist
```
**A single seat scoring <=4 caps the FINAL at 69 regardless of the total.** One broken link is
enough — a perfect video with a dead hook is a dead video.

## PART 3 — THE DEBATE LEDGER (what the tournament actually produced)

For every competing seat, record what was killed. **This is where the system learns.**
```
SEAT            WINNER   WHY IT WON                    KILLED (A / C)
Strategist      C        no page has posted this        A: generic comparison · C-alt: too niche
Scriptwriter    B        two-layer, precedent cited     A: text-only hook · C: unrenderable
Director        C        the plate-anchored move        A: parked-car open · B: standard orbit
Emotion         B        conflict, not a state          A: "excited" · C: too subtle for 15s
Transition      C        wheel -> sun match cut         A: hard cuts · B: whip
```
**Rules:** the obvious option (A) must appear in every row and must lose. If A ever wins, the seat
did not try — send it back. Every killed idea is logged; some become next video's winner.
