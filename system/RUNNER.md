## PHASE 1 — DECIDE   (free, no credits)

> ⚡ **FAST LANE:** a series episode forked from a ✓-proven exemplar (S1–S5) skips the double scorecard — run the free gates + Wow Test + ONE combined /60 check, then straight to approval. Full ceremony is for new concepts and hero builds; the machine shouldn't re-prove what's already proven.

**You give:** a fragment ("something about the LC300").

**0. Trend-scan + target** *(deep: files 08 · 14)* — scan what's working this week (ride it or counter-program it), then lock: **AVATAR · PILLAR + ep# · LANGUAGE mode.** No "for everyone" videos.
**1. Interpret** → 2–3 angles. Pick one. *(deep: file 08)*
**2. Script the 4 beats + loop** — fork from the nearest **swipe-file exemplar** (S1–S5, file 02), don't start blank:

```
HOOK   — type? (transition/visual/emotion/pattern-break) + WOW or TWIST in 2s
VALUE  — which of the 6? (knowledge/comedy/relatable/aspiration/utility/identity)
TWIST  — what makes them SEND it?
CTA    — the ONE ask (comment-bait that points back to the hook)
LOOP   — last frame → first frame. Under 12s.
```

**2b. ⚡ J0 — THE HOOK ASSASSIN judges the opening FIRST** *(deep: file 06)*. Absolute veto on the first seconds: frame-1 still test · the 1-second stack (visual+text+verbal) · motion · a nameable SPECIFIC promise · 10–14 words · delivered by 15s · fresh-for-2026. Any miss caps at 6/10; two misses = auto-kill back to Scriptwriter (pull from Bank 11 visual hooks). A 9/10 video with a 4/10 hook is a 4/10 video.

**3. Gate it — all must pass, or rewrite (still free):**
```
□ FREEZE FRAME 1 — something HAPPENING, not someone POSED   ← #1 killer
□ Idea DETONATES in ≤1.5s — no studying required
□ Frame 1 has WOW or TWIST
□ Delivers ≥1 value type
□ Twist makes the sharer look good
□ CTA loops back to hook
□ Legible SOUND OFF
```

> ⚠️ **Aspiration-only = fail.** Beautiful and forgettable is the default trap.
> ⚠️ **Posed-then-moves = fail.** A premium frozen opening is the *seductive* trap — it looks done. Motion lives in frame 1 or the scroller is already gone. (Learned from a real twin-split test: gorgeous, clever, un-scrollable.)

**4. Spec the shot — BANKS FIRST:** *(assets: file 13 · deep: files 05 camera · 03 performance · 07 emotion · 04 sound)*

Invent only when no asset fits — and add the invention back to the bank with a log row.

```
CAMERA   — body + lens + T-stop        (T5.6 deep if bodies must be countable)
PERFORM  — WEIGHT. Hands need a JOB. Head-first-eyes-follow. Reset to neutral.

           physically continuous across it. Designed at BUILD, not rescued in the edit

MUA      — skin texture recipe · flyaways ON · wardrobe locked verbatim across clips · APPROVES every generated character image before it becomes a reference (scores inside PERFORM line)

SOUND    — audio ON if sound-led (POV/interior). OFF if multi-clip stitch.
MODERATION — zero appearance words. References carry WHO.
```

**5. ⚡ BUILD SELF-SCORE — the crew grades its own spec**
Each build seat scores its contribution 0–10. Gate at **≥8 each, ≥48/60.**
```
DIRECTOR      /10   blocking clear · no occlusion · countable
PERFORMANCE   /10   weight written · hands have a job · staggered
EMOTION       /10   a named conflict, not a state · 3 phases
DOP           /10   motivated light · reflections · right DOF
FOLEY         /10   hero sound named · foley per beat · drop-outs placed · audio ON/OFF call
TECH          /10   model fits · settings right · cost sane · disclose-AI noted
──────────────────
BUILD SCORE   /60   → below 48, or any seat <8 = back to that seat
```
> All free. Sends a weak spec back to its seat before anything is judged.
> **Foley is its own line now** — it was folded into Tech, which is exactly how sound got treated as an afterthought. Every seat scores separately so none can be skipped.

## PHASE 3 — JUDGE THE PLAN   (still free — nothing generated yet)

**6. Judge the storyboard, not a clip.** The five judges score the *plan* — the shot list, the hook description, the beats — against everything they'd look for. QA reviews the spec for known-broken risks (twin merge, four hands, badge). *(deep: file 06)*

**6a. ⚡ J0 THE HOOK TYRANT — the first-10-seconds super-critic, runs before everything** *(deep: file 06)*
Solo VETO. The 10-second map (grab complete by 2.0s · interrupts at ~3s and ~7s · promise paying by 5s) + hard auto-caps (no visual hook ≤4 · slow build ≤3 · generic ≤6). Score ≥8 or the plan goes back to the Scriptwriter before the panel ever sits.

**6b. ⚡ THE WOW TEST v2 — runs FIRST, adversarial, four sub-tests** *(deep: file 06)*
The plan is NOT WOW until proven. It must pass all four:
```
□ SCREENSHOT — name the ONE frame that stops a thumb (not "a hand doing a normal thing")
□ PRECEDENT  — cite a specific video where this hook mechanism already went viral
□ REFERENCE  — at least as wow as YUNER / Douyin / the selfie (score vs THEM, not abstract)
□ FORMAT     — not logged-weak; POV/first-person caps wow at 5 regardless of concept
```
> **The honest rule:** the paper Wow Test judges *concept-wow* only. It is BLIND to *execution-wow* (that's the clip-score, after render). Passing = "worth generating." It NEVER means "this will wow." **A weak-format concept (POV) cannot pass on concept alone — fix the format or accept it's a value play, not a scroll-stopper.**
> **Smart ≠ wow.** A clever fact earns a nod (Mode B value). A wow earns a stop. Label which one it is honestly, up front.

**7. ⚡ PLAN SELF-SCORE — the panel grades the storyboard**
Each judge 0–10 on the plan. Gate at **≥8 each, ≥48/60** — AND the Wow Test must be genuinely passed, not self-flattered.
```
J1 SCROLLER   /10   would this hook stop me? (posed frame 1 = auto ≤4; smart-not-wow ≤6)
J2 EYE        /10   does the concept read as new? (no precedent cited = ≤5)
J3 CRITIC     /10   is the idea any good?
J4 LOCAL      /10   car right in the plan? cringe? (language mode lands? — file 14)
J5 BUYER      /10   is there a next step designed in?
J6 ALGORITHM  /10   Group re-share? DM-send moment? session-extend? (no engineered share-trigger = ≤5)
──────────────────
PLAN SCORE    /60   → below 48, any judge <8, OR Wow Test unproven = fix the plan
```
**Panel duties every run** *(deep: file 06)*: forced ranking vs the 3 reference videos · the KILL QUOTA (name + replace the weakest beat even on a pass) · the COMMENT SIMULATION (5 realistic comments in the avatar's voice — all "nice video" = CTA failed) · the PER-BEAT RETENTION PREDICTION (3s/15s/end %, later overlaid against the real curve — the calibration signal).

**8. ⚡ STRATEGIST REGENERATES THE PLAN — the free loop closes**
The Strategist reads BOTH paper scores (build + plan) and:
```
Both ≥ threshold   → the plan is proven; go to YOU
Build failed       → back to the seat that scored <8
Plan failed        → route by beat: hook→Scriptwriter · look→DOP · idea→Strategist
Passed but < great → re-brief once, aim higher, re-score
```
> This whole loop is **free** — it runs on the storyboard, not credits. It repeats until both paper scorecards clear.

## PHASE 4 — APPROVE & GENERATE   (the ONE spend)

**9. ⏸ YOUR SINGLE APPROVAL.** You see: locked script · storyboard · BOTH scorecards · preflighted cost. Only a plan that already cleared build-score AND plan-score reaches you. Your GO is the only spend authorization in the whole pipeline.

**9b. ⚡ HOOK-FIRST PROTOCOL — test the hook before building anything** *(preset: Bank 9 #25 reroll ladder)*
> J0 and the Wow Test judge the hook on PAPER. Only pixels prove it. This buys insurance for the price of a coffee.
```
1. Generate ONLY the hook beat — 2–3 COMPETING hooks from Bank 2, not one
2. Cheap tier: 5s · 720p · fast mode (~17.5cr each → ~35–50cr for the whole test)
3. Put them side by side. YOUR thumb decides which one stops it — not a score
4. Winner → rebuilt at full 1080p std and the build proceeds
   Losers → discarded, cost = one coffee, lesson logged
5. Write-back: the winning hook asset gets tagged ✓ proven + its prompt block appended (file 13)
```
**Why it matters:** every hook failure this system shipped passed its paper gates and died in the render. This is the only step that tests *execution-wow* before the full spend. Skip it only on a Fast Lane episode reusing a ✓-proven hook.

**10. Generate** *(deep: file 02 Technologist)* — clip-by-clip, test cheap first.
```
Test? 5s/720p = 17.5cr   →   Final = 90–135cr
```

**11. CLIP SELF-SCORE — grade the real footage.** Now the judges score the *generated clip* (QA fatal = reroll). Same /60 bar. A clip that renders worse than its plan promised loops back per the collision rules — but the *idea* is already proven, so this only catches render failures (merge, melt, drift), not concept failures.

**11b. ⚡ THE EDITOR — assemble with rhythm.** *(deep: file 10 · recipes: file 11 · sounds: file 12)* Never edit from scratch: **pick a recipe from the Editing Bank** (hero single-take / 4-beat spine / chaptered long-form / velocity montage / POV) → fill its slots → drop SFX by beat-type from the **Foley Bank** (the beat→sound-ID cheat) → one music bed per the bank's rules → output the auto-edit spec. Transitions are designed at BUILD (how each clip ends/begins), not rescued here.

**11c. ⚡ MASTER SCORECARD** *(file 26)* — score the WINNING proposal from every seat's tournament.
Hard gates first (mechanical, a fail = no ship, no score). Then the weighted /100: **J0 hook ×3.0 ·
Strategist ×2.0 · twist ×2.0 · J6 share-trigger ×1.5**, execution seats ×1.0, transitions/tech ×0.75.
**Any single seat ≤4 caps the final at 69** — one broken link kills the video. Log the DEBATE LEDGER
(what each seat killed and why) and commit to a retention PREDICTION before posting.

LAUNCH → read the real curve → feed the next video.** *(deep: files 15 · 08)* Post per the Launch Protocol — FB Reels 6–9pm (9pm peak) · pre-launch checklist (pinned comment drafted, Groups list, disclose AI) · the first-hour drill (reply to EVERY comment with a question, never "thanks") · the 24-hour read overlays predicted vs actual curve = the calibration signal.

## ⚖️ WHEN GATES COLLIDE — the priority order

The one thing the deep files don't resolve. **Higher wins:**

```
1. MODERATION        (a blocked video is worth nothing)
2. THE HOOK          (no stop = nothing else happened)
3. THE LOOP / <12s   (retention is the whole game)
4. ONE VALUE TYPE    (must deliver something)
5. everything else   (polish, emotion depth, camera craft)
```

**Worked collisions:**
- *Loop wants <12s, but the review needs 25s to explain?* → It's **Mode B**. Retention rule relaxes; knowledge wins. Loops are for **Mode A hero**, not reviews.
- *Emotion wants slow held beats, Scroller wants motion?* → **Hook first (rule 2)**: motion opens, the held emotional beat is the *reward* at the midpoint, not the opener.
- *Sound-led wants audio ON, but it's a multi-clip stitch?* → **Stitch wins.** Generate silent, add one bed in the edit. A sound-led idea that must be stitched should be **one clip instead.**

## THE 5 THINGS THAT ACTUALLY DECIDE IT

If you remember nothing else:

1. **Frame 1 = WOW or TWIST.** No exceptions.
2. **Loop the ending to the start.** Biggest retention lever.
3. **Aspiration-only is the trap.** Always stack a second value type.
4. **Weight + conflict = alive.** Bodies have mass; faces manage feelings.
5. **The four gates are free. The generator is not.** Kill bad ideas before you pay.
