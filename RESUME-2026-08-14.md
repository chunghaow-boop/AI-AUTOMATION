## THE THREE BUGS THIS BUILD FOUND

### L173 — the worst one, because it was completely silent
Card PNGs were passed to ffmpeg as bare `-i card.png`. That is a **one-frame stream at
pts=0**; capcards then applies `fade=t=in:st=<start>:alpha=1`, which at pts=0 is fully
transparent, and `overlay`'s default `eof_action=repeat` holds that transparent frame for
the whole film. PNGs correct on disk, manifest correct, filtergraph correct, enable=
windows correct, **ffmpeg exit code 0** — and not one caption in the output.

Found by diffing a built frame against its own source clip and getting *"frames are
identical"*. Fix: `-loop 1 -framerate FPS -t DUR` before each PNG.

> **A DECLARED LAYER MUST BE MEASURED IN THE OUTPUT, NEVER ASSUMED FROM A CLEAN EXIT
> CODE.** Exit 0 means ffmpeg understood you, not that it did what you meant.

Mechanized as **verify check 21 CARD PRESENCE** — measures the built frame against its
source inside the declared card band. Proven in isolation: **band 40.70 when visible vs
0.91 when invisible**. Not yet run against a real build (needs clips + film together) —
treat its first green here as unproven.

### L171 — an earned cut cost the film its whole-clip status
One justified trim flipped `planqc._is_whole_clip` to False, which silently **re-armed
checks 2, 9 and 21 as blocking** — and a 6-shot whole-clip film can never satisfy a
burst-cut profile's cuts/min or a 2.27s hook ceiling. The plan was right, the gate was
wrong. HARD RULE 0 says a cut is EARNED, not that there are none. Fixed + negative control.

### L172 — `CARD_STYLE` is two namespaces with one name
`"fragment"` is a *writing* convention (9 of 10 plans declare it); `captionmgr.STYLES` is
a *render* vocabulary. Passing one into the other raises `KeyError`. build_niah.py only
survived by hardcoding `style="punch"` — correct, but never written down.
